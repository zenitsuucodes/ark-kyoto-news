----------

習主席、11月にトランプ大統領と再び会談する計画で訪米を締めくくる

ワシントン - 中国の習近平国家主席は金曜日、約2か月後にドナルド・トランプ米大統領と再度会談する計画で3日間のワシントン国賓訪問を終えた。

最終日にホワイトハウスでお茶を飲みながら談笑した際、トランプ大統領は、南部の都市深センでアジア太平洋経済協力フォーラム首脳会議が開催される11月中旬に中国を訪問するという習氏の申し出を受け入れた。

----------

焦点：トランプ氏にとっては内容ではなく習氏との首脳会談の頻度がより重要かもしれない

ワシントン - 2025年に大統領に復帰して以来、ドナルド・トランプ米大統領はすでに中国の習近平国家主席と3回直接会談しているが、会えば会うほど会談の内容は表面的なものになっているように見える。

豪華さと雰囲気に満ちた習氏の３日間にわたるワシントン国賓訪問は、何の驚きもなく金曜日に終了した。

----------

日米共同訓練、日本の長距離ミサイルを活用した訓練を10月に開始

東京 - 10月に始まる大規模な日米共同訓練には、陸上自衛隊の長距離ミサイルが参加する見通しであると防衛省関係者が土曜日に明らかにした。

25式地対艦誘導弾は、緊急時に敵領土を直接攻撃するいわゆる反撃能力として、3月に南西部の熊本県に配備された。

----------

中部地方の名古屋テレビ塔で火災、負傷者は出ていない

名古屋 - 日本の中心部の都市、名古屋市のランドマークである名古屋テレビ塔で土曜日に火災が発生したが、負傷者の報告は入っていない。

目撃者から正午ごろ塔の中央部から煙が出ているとの緊急通報があった。市消防​​局によると、火は午後１時２０分ごろに消し止められた。

----------

大相撲：大野里がまた破り、青錦が勝って大団円を飾る

東京 - 土曜日、横綱大野里が2日連続で敗れ、大関青錦が勝って大相撲秋場所の魅力的なフィナーレを飾り、両力士は11勝3敗でリードを引き分けた。

東京・両国国技館で行われたその日の決勝戦で、勝てば1勝のアドバンテージが保てると知った大野里は、大関琴桜（9勝5敗）に対して右脇の下でソフトホールドを確保した後、すぐに攻撃を開始した。

----------

アジア大会：11歳の日本の栗原選手がeスポーツでパズル金メダルを獲得

名古屋 - 代表団の最年少メンバーである日本の11歳の栗原勇輝が、土曜日に愛知・名古屋アジア大会のパズル決勝で優勝し、大陸大会で同国初のeスポーツ金メダルを獲得した。

栗原選手は、愛知県常滑市で開催されたぷよぷよチャンピオンズで、準決勝でタイのタナラック・ウォンキティクン選手を破り、韓国のカン・ドンシン選手を10-2で破った。

----------

アジア大会：雨でキャンペーン終了後も日本のクリケットは前向きな見通しを維持

日進、日本 - 開催国である日本は、土曜日に愛知・名古屋アジア大会男子クリケットのキャンペーンが雨で終了し、ネパールとのグループA最終戦は中止となったが、チームはこの大会から前向きな姿勢を見せている。

アフガニスタンに初戦で敗れた後、世界41位の日本は興梠運動公園で14位のネパールを破り、大会存続を目指していた。

----------

アジア大会主催者、問題と観客動員の苦境を謝罪

名古屋 - 愛知・名古屋アジア大会の組織委員会は土曜日、アジア版オリンピックが折り返し地点に達する中、宿泊施設や交通機関を巡る一連の問題について謝罪した。

組織委員会の村手聡事務総長は名古屋市で記者会見し、「私たちに責任があり、心からおわびする」と述べ、職員らが同様の問題が再発しないように努めていると述べた。
